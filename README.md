# 麦麦周边雷达 (McdMerchRadar)

> 第一时间掌握麦当劳中国的**周边 / 联名新品上新情报**，并高亮"先领哪几张券、再下单最划算"。
> 一个聚焦、可复现、纯标准库实现的麦当劳 MCP 创意 Skill。

---

## 这个项目解决什么痛点？

很多人（包括作者本人）喜欢为麦当劳的周边消费，但总有这样的遗憾：

- **周边上新了，但我不知道** —— 联名徽章、限定丝巾、GD 同款棒球帽，往往只在活动日历里挂几天；
- **知道有活动，却没领券，白亏了** —— 周边基本是"任意餐品消费 + 加价"模式，而你的券库里躺着好几张能摊薄门槛的券；
- **积分快过期了，却没攒够换周边** —— 到底该抽还是该换，心里没数。

**麦麦周边雷达**把这三件事每周自动理清楚，输出一份带行动清单的《本周情报》。

---

## 功能

| 模块 | 说明 |
| --- | --- |
| 🔔 周边上新雷达 | 解析活动日历，挑出**未来的**周边 / 联名类活动，标注开售时间、加价门槛 |
| 🎟️ 未领券提醒 | 列出你**还没领**的优惠券（多数能直接摊薄"任意餐品消费 + 加价"门槛） |
| 💰 积分体检 | 可用 / 累计 / 本月 & 下月将过期积分，以及当前能抽几次奖 |
| 🧾 行动清单 | 把"未领的券"和"即将开售的周边"自动配对，告诉你先领哪几张再下单 |

> 注意：本 Skill **不调用任何下单接口**，所有购买决策由你完成。它只做情报与建议。

## 安装

### 1. 申请麦当劳 MCP Token

1. 打开 [麦当劳 MCP Server 仓库](https://github.com/M-China/mcd-mcp-server)，点击右上角【登录】；
2. 用手机号验证登录，右上角变为【控制台】；
3. 打开控制台 → 点击【激活】申请 MCP Token → 一键复制。

### 2. 准备运行环境

本 Skill 仅使用 Python 标准库，无需 `pip install`。

```bash
# 需要 Python 3.8+
python --version
```

### 3. （可选）在 WorkBuddy 里启用 MCP

左侧【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer 你的MCP_TOKEN"
      }
    }
  }
}
```

保存后回到【自定义连接器】将 `mcd-mcp` 启用即可。

## 使用

```bash
cd mcd-merch-radar
export MCD_MCP_TOKEN="你的麦当劳MCP_TOKEN"

# 打印本周情报（Markdown）
python scripts/briefing.py

# 输出结构化 JSON（便于二次开发 / 接入定时任务）
python scripts/briefing.py --json
```

示例输出（节选，真实数据）：

## 目标用户

- 喜欢麦当劳周边 / 联名的"麦门信徒"；
- 不想错过限时活动、又总忘记领券的人；
- 想用积分 / 优惠券把周边"更合适地拿到手"的精明消费者。

## 技术说明

- **零第三方依赖**：仅用 `urllib` / `json` / `re` / `argparse` 标准库，便于任何环境复现；
- **只读安全**：只调用查询类工具，绝不触碰 `mall-create-order` / `party-order-create` 等下单接口；
- **Token 不落盘**：Token 仅通过环境变量 `MCD_MCP_TOKEN` 传入，仓库内不含任何真实凭证；
- 详见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)。
